# #16 — Map: MapLibre with OpenFreeMap tiles

Parent: #2 · Epic spec: [02-the-report](../remediation/specs/02-the-report.md) · Status: draft

## Problem

The old app had Leaflet with OSM tiles and boundary overlays. The rebuild has no
map, and the operator's instruction is explicit: use the open-source mapping
stack rather than drawing anything ourselves.

## Approach

- **MapLibre GL JS** (BSD-3) for rendering, about 200 KB.
- **OpenFreeMap** for the style and tiles: keyless, no registration, no tracking.
- **Boundary overlay** from Census cartographic boundary GeoJSON, downloaded at
  build time into `data/boundaries/` and served from our own origin, so the
  outline never depends on a third party.
- **Placement:** 200px tall, beside the header block. It
  answers "where", then gets out of the way.
- **Offline:** if tiles fail, the GeoJSON outline still draws. No error message.

The boundary file also serves #9 (use my location) for point-in-polygon.

## Acceptance criteria

- [ ] The map renders with the overlay at every place page
- [ ] With tiles blocked, the outline renders and no error appears
- [ ] It does not push the panels below the fold at 1440×900
- [ ] It adds no third-party request on a place page other than the tile fetch
- [ ] The boundary GeoJSON is served from our origin with a cache header

## Risks

External dependency for tiles. OpenFreeMap is free and keyless today; if it
disappears the map degrades to an outline, which is the designed failure mode.

## Out of scope

National choropleth, click-to-navigate, zoom-linked data, boundary editing.
